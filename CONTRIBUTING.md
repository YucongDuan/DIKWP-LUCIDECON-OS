# Contributing

Start with a reproducible issue: version, command, minimal synthetic input, expected result and actual output. Preserve purpose and permission boundaries, uncertainty, adverse evidence and integer money accounting. Do not upload private keys, bank records or personal financial details. Run the documented tests before submitting a pull request.

Useful first contributions include clearer quick starts, synthetic counterexamples, translation corrections and independently reproduced results. Credit original sources and preserve the applicable license.
